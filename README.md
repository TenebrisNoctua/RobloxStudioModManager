# Roblox Studio Mod Manager (Luau)

This repository is the full source of the Roblox Studio Mod Manager application, ported from [MaximumADHD](https://github.com/MaximumADHD/)'s Roblox Studio Mod Manager project, from C# to Luau.

The application uses Fusion and Fusion Foundation, albeit heavily modified to run on Luwow.

This application requires the [Luwow](https://github.com/Luwow-Project/Release/releases/latest) runtime engine, and the [extended libraries](https://github.com/TenebrisNoctua/Extended-Libraries/releases/latest) in order to be compiled and working, however the [releases](https://github.com/TenebrisNoctua/RobloxStudioModManager/releases/latest) should contain a zip file for MacOS and Windows with ready-to-use builds.
